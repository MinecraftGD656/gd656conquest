# 行动音乐状态机（0.1.14）

协议为 `bf1-0.1.14`，客户端和服务端须一起更新。服务器同步阶段和防抖后的音乐等级，客户端根据实际音频结束状态、个人部署状态和资源包素材决定播放；旧的行动开战、撤退、据点内、最后据点、最终区域、零兵力及死亡背景曲不再与新主背景并行。

## 流程

| 节点 | 事件（均使用 gd656conquest 命名空间） | 行为 |
| --- | --- | --- |
| 第一营正式开局 | music.operation.round_start1 | 全员单次播放 |
| 第二／第三及后续营正式开局 | music.operation.round_start2／round_start3 | 按营数选可用编号；当前第三营回退至2 |
| 拿下非最终区域，存在撤退名单 | music.operation.attackers_advance1–5 | 按刚拿下区域编号选择，双方相同，循环至清理结束；当前4／5回退至3 |
| 无撤退名单，或清理完毕 | music.operation.round_start1 | 立即播放，在5秒准备进攻倒计时开始处触发；推进曲快速淡出0.5秒 |
| 推进倒计时结束 | 延续已有RoundStart | 同一营／目标区域身份不重复起曲 |
| 本营／最终结果 | music.operation.eor_win／eor_lose | 按本轮胜负直接单次播放，无淡入淡出；最终页面不重播 |
| 非终局结果曲结束而尚未部署 | loop.deploy_screen | 直接接续部署循环；个人部署停止接续音乐 |
| 下一营正式开局 | 对应RoundStart | 接管所有玩家音乐，包括仍未部署者，不保留上一营EOR |

首次部署准备保留部署音乐，RoundStart等待正式开战。普通战斗中没有主战况音乐时，打开部署界面可继续使用部署循环。大厅与匹配音乐沿用原流程。

终局EOR播放完后保持安静，退出房间清理。最终演出结束后仍等待原有30秒退房，不延长流程；默认36秒演出加30秒等待短于新EOR的77／118秒，因此退房时可能中断EOR。

## 决战条件

所有据点判断只统计当前区域有效据点。中立指归属为空；最后据点被扯动指进攻占领进度大于零的容差值，不沿用旧25%条件；完整防守控制要求归属防守且占领进度恢复到底。

| 场景 | 进入／升级 | 恢复／降级 |
| --- | --- | --- |
| 普通营、普通区域 | 兵力≤20，或只剩一个未拿下据点且中立，进入01；零兵力争夺延续01 | 兵力≥30解除低兵力原因；任意当前区域据点完整防守控制连续10秒解除据点原因；所有有效原因解除才退出 |
| 最后一营、普通区域 | RoundStart结束后01；兵力≤50进入02；≤20进入03 | 兵力≥30允许03→02；≥60允许02→01 |
| 普通营、最后区域 | RoundStart结束后01；任意据点中立进入02；最后一个未拿下据点开始被扯动进入03 | 任意据点完整防守控制连续30秒允许03→02；全部当前区域据点完整防守控制连续10秒允许02→01 |
| 最后一营、最后区域 | 对应兵力或据点条件任一满足即可升级 | 对应兵力和据点条件均满足才降级 |

特殊场景的02／03可以打断尚未结束的RoundStart；01底层等待开局曲实际结束。特殊场景零兵力争夺锁住03。完整控制计时分别记录每个据点，另一据点也可触发恢复，不把不同据点的短时间累加；音乐升级不清空既有控制计时。全控计时连续成立，任一点失控就清零。多个降级条件同时满足时直接到目标等级，只做一次交叉淡化。

01／02／03事件分别为 `music.operation.pre_eor_01`、`pre_eor_02`、`pre_eor_03`，均循环。首次进入01淡入1秒，普通场景退出淡出3秒；降级旧曲淡出1秒、新曲同时淡入1秒。升级旧曲短淡出0.3秒，新曲直接起播，并单次插入 `music.operation.pre_eor_overlay`；已有Overlay尚未结束时复用，不叠加另一个实例。

占领、营结束和服务器零兵力判负优先于音乐防抖，不等待10／30秒。兵力恢复使用固定人数，低于30／60的兵力上限不会改成比例阈值。

## 位置、淡化与资源包

每阶段分别记录三首PreEOR的播放位置；返回曾播放的曲目时优先从自己的书签接续，首次切换到另一首时取当前PreEOR的位置，对目标曲长取余。首次从RoundStart进入PreEOR从零开始。新阶段／新营清除书签和防抖状态。偏移是播放时间近似值，不保证曲目不同长度下的小节对齐。

音频在后台解码并跳过偏移PCM；循环由流式解码器正常重复全曲。播放时长从当前资源包实际OGG测量，位置及淡化时钟等流加载就绪后开始。允许零音量音乐实例启动，避免SoundEngine跳过淡入曲；交叉切换的旧曲等待目标流准备好才推进淡出，周期状态包不重置淡入或重播同曲。

EOR期间时间轴实际声音将主曲压至25%，全部结束恢复，不修改时间轴自身音量或进度。新战斗自动语音保持独立队列。

素材位于 `assets/gd656conquest/sounds/music/operation/`，11个WAV已转为小写名称的Vorbis OGG，通过解码检查后删除原件。RoundStart3及Advance4／5已注册对应资源路径，客户端检测到无实际文件时回退到较低最高可用编号。未来资源包只需提供下列同名文件，重新加载资源后即可参与选曲，无需另写声音事件：

- `assets/gd656conquest/sounds/music/operation/mp_music_set_roundstart3_wave.ogg`
- `assets/gd656conquest/sounds/music/operation/mp_music_set_attackersadvance_wave4.ogg`
- `assets/gd656conquest/sounds/music/operation/mp_music_set_attackersadvance_wave5.ogg`

注册形式如下：

```json
"music.operation.round_start3": {
  "sounds": [{"name": "gd656conquest:music/operation/mp_music_set_roundstart3_wave", "stream": true}]
}
```

自动检查覆盖四类场景、防抖连续性、任意其他据点恢复、已有计时、组合条件、直接降级、零兵力、书签、编号回退和网络往返；音乐对象检查覆盖静音启动、加载就绪、同步淡化和PCM偏移。未运行实际多人客户端或OpenAL试听，实机应检查不同GUI／资源包组合与长曲切换听感。
