# 撤退恢复与补给箱生命值（0.1.17）

客户端和服务端均须升级至0.1.17，协议为 `bf1-0.1.17`。开局与EOR规则见[行动音乐状态机](operations-music.md)。

## 撤退成功立即恢复

行动房间规则新增“撤退成功立即恢复”，配置ID `btRetreatSuccessRestore`，存储路径 `breakthroughConfig.retreatSuccessRestore`，默认true。旧地图缺少该字段也默认开启，可在房间配置界面或原有房间配置命令中修改。关闭后仍保留正常撤退判定和本人撤退成功语音，跳过回血与配装恢复。

恢复与实际撤退成功确认同时执行，每次撤退每人仅一次。玩家须为撤退名单中的防守方，存活、非旁观、非重部署状态，并抵达下一防区；死亡、重新部署或名单清空本身不发放恢复。

正常部署发装后记录本次实际发放的完整装备，领取英雄装备时更新记录，绑定房间与对局。成功撤退时使用该记录恢复物品、手雷、支援装备、护甲与备弹，不读取配装界面中尚未部署的选择，不重新随机武器或配件。仍持有同种枪械时保留其武器及配件标签，补满弹匣；TACZ取消当前换弹并补齐枪膛与虚拟备弹，SBW补满弹匣、恢复本次部署备弹并结束换弹计时。此奖励不受普通弹药箱补给资格、受伤冷却或补给冷却限制，不产生医疗／补给积分。

恢复后生命值设为玩家当前最大生命值，不附赠无敌或清除其他效果。没有有效的本次部署记录时，只恢复生命值，避免误发另一房间、旧对局或尚未部署的新配装。

## 全局补给箱生命值

全局配置新增 `supplyBoxHealth`，中文别名“补给箱生命值”，默认50。普通医疗箱和普通弹药箱共用该值，创建时同时设置最大生命值与当前生命值。修改后对新生成的普通箱子生效，已经存在的箱子不因改配置自动回血。

```text
/gdc config get supplyBoxHealth
/gdc config set supplyBoxHealth 50
```

命令接受1至1024，包括小数；配置文件中缺失、null、非有限值或非正数回退50，正数按实体属性范围限制。中文别名须加引号，例如 `/gdc config set "补给箱生命值" 50`。

地图预配置的永久医疗箱／弹药箱仍为100点生命值并保持免伤与无限使用，不使用本项配置。生命值配置不改变医疗箱的治疗储量或弹药箱的使用次数。

自动检查覆盖默认值、旧配置迁移、关闭与保存、修改地图数据组后保留关闭状态、命令别名、首营音乐提前与战斗解锁不变、后续营时序保留，以及恢复快照的对局隔离和不可变性。未进行实机多人撤退补给与音频试听。
